# PrecioCR

MVP de un comparador inteligente de precios para Costa Rica.

## Ejecutar localmente

```bash
npm install
npm run dev
```

Luego abre `http://localhost:3000`.

## Deploy en Vercel

1. Sube todos los archivos de este proyecto a GitHub.
2. En Vercel, importa el repositorio.
3. Vercel detectará Next.js automáticamente.
4. Pulsa Deploy.

## Nota

Esta primera versión usa datos demostrativos. La arquitectura ya está preparada para sustituirlos por fuentes reales mediante APIs, feeds o integraciones permitidas.
